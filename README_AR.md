# مجلس التداول الذكي — النسخة العربية

واجهة عربية من اليمين إلى اليسار لإدارة مجلس مكوّن من أربعة وكلاء تحليل. هذه النسخة **للمحاكاة فقط**.

## ما الذي يعمل الآن؟
- لوحة عربية RTL.
- عرض أسعار اصطناعية لست عملات.
- أربعة وكلاء تجريبيين بقواعد واضحة.
- شرط إجماع 4/4 قبل إظهار قرار شراء/بيع.
- سجل صفقات ورقي محلي ورصيد افتراضي.
- إعدادات للمخاطرة والرافعة التجريبية.
- لا يتطلب مفاتيح API أو عبارة استرداد.

## ما الذي لا يعمل؟
- لا توجد بيانات أسعار مباشرة.
- لا يوجد اتصال فعلي بـ Phantom أو Hyperliquid.
- لا يوجد تنفيذ تداول حقيقي.
- الوكلاء قواعد توضيحية وليست نماذج تنبؤ مدربة، والنتائج لا تعني توقع الربح.

## التشغيل على الكمبيوتر
يتطلب Python 3.10 أو أحدث.

1. فك ضغط الملف.
2. افتح الطرفية داخل مجلد المشروع.
3. أنشئ بيئة افتراضية:

   **Windows**
   ```bash
   py -m venv .venv
   .venv\Scripts\activate
   ```

   **macOS / Linux**
   ```bash
   python3 -m venv .venv
   source .venv/bin/activate
   ```

4. ثبّت المتطلبات:
   ```bash
   pip install -r requirements.txt
   ```
5. شغّل الواجهة:
   ```bash
   streamlit run app.py
   ```
6. افتح عنوان localhost الذي يظهر في الطرفية، غالبًا `http://localhost:8501`.

## الاستخدام
1. افتح «لوحة السوق» واضغط «تحديث بيانات المحاكاة».
2. اختر العملة واضغط «تشغيل الوكلاء الأربعة».
3. إذا لم يتفق الأربعة على شراء أو بيع، فالقرار انتظار ولا تُفتح صفقة.
4. عند الإجماع الكامل فقط، يمكن إنشاء صفقة ورقية.
5. سجل الصفقات محفوظ محليًا في `data/paper_trades.json`.

## الأمان والانتقال إلى بيانات حقيقية
لا تدخل عبارة استرداد Phantom أو المفتاح الخاص في هذا البرنامج. لا تضف صلاحيات سحب إلى أي مفتاح تداول. قبل أي تكامل مستقبلي، يجب استخدام بيانات سوق موثوقة، وبيئة اختبار رسمية إن توفرت، ومفاتيح بصلاحيات محدودة، وحدود خسارة وإيقاف طارئ، واختبارات مستقلة. توفر Perps يختلف حسب المنطقة. لا يمكن ضمان الربح.

## ملاحظة
هذه نسخة بداية تعليمية. قبل استخدامها على أموال حقيقية يلزم تطوير ومراجعة أمنية واختبار خلفي على بيانات تاريخية، وليس مجرد تغيير زر من «تجريبي» إلى «حقيقي».
